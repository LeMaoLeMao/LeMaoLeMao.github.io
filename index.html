Interactive Quadrupedal Navigation through Active Contact Sensing

Work in Progress

Developed an interactive navigation framework that uses RRT for high-level path planning, actively probes potential obstacles with whiskers to estimate traversability from force feedback, and dynamically updates the global map for replanning.

Meta-Learning for Fast Multimodal Adaptation

Work in Progress
